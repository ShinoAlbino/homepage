## 1. 何が変わったか

### データ構造

```js
{
  id, category, license, point,
  question, choices, answer, explanation,
  source, verified
}
```

| フィールド | 内容 |
|---|---|
| `category` | 本試験の出題4分野 `law` / `gear` / `knowledge` / `management` |
| `license` | 適用免許の配列 `"net"` `"trap"` `"gun1"` `"gun2"` |
| `point` | 例題集「知識試験例題の出題ポイント一覧」の分類 |
| `source` | 根拠条文・出典 |
| `verified` | 最終確認日。法改正時に「何年も未確認の問題」を機械的に洗い出せる |

旧 `category` の `"gun"` `"trap"` は `"gear"` に統合し、免許の出し分けは `license` が担う。これにより**猟具ごとの4種類の模擬試験**が組めるようになった。

### 分類の是正

例題集の分野定義に合わせて、誤って分類されていた問題を付け替えた。

- `gun13` `gun27`〜`gun30`（銃猟の時間規制・方向規制・捕獲禁止場所）→ **法令**へ
- `trap01` `trap04` `trap05` `trap12`〜`trap14` `trap23`（猟法の規制・猟具の標識）→ **法令**へ
- `trap07` `trap17`（錯誤捕獲）→ **保護管理**へ
- `mng04` `mng05` `mng11` `mng12` `mng18` `mng19`（鳥獣保護区・休猟区・法の目的・猟区）→ **法令**へ

## 3. 模擬試験の実装

例題集 p.23 に明記された本試験の配分（法令13／猟具6／鳥獣9／保護管理2）で抽出する。

```js
const shuffle = a => a.map(v => [Math.random(), v])
                      .sort((x, y) => x[0] - y[0])
                      .map(v => v[1]);

// L = "net" | "trap" | "gun1" | "gun2"
const makeMockExam = (L) =>
  [["law", 13], ["gear", 6], ["knowledge", 9], ["management", 2]]
    .flatMap(([cat, n]) =>
      shuffle(QUESTIONS.filter(q => q.license.includes(L) && q.category === cat)).slice(0, n)
    );
```

**検証済み**：4免許 × 100回 = 400回生成して、すべて30問・ID重複なし・免許整合を確認。

> 現行の単純ランダム抽出のままだと保護管理が過剰に出る。本番と体感を揃えるため、この固定比率での抽出に差し替えること。

### 通常演習のフィルタ

```js
// 免許で絞る
QUESTIONS.filter(q => q.license.includes(selectedLicense));

// 分野で絞る
QUESTIONS.filter(q => q.license.includes(L) && q.category === selectedCategory);

// 論点で絞る（弱点対策）
QUESTIONS.filter(q => q.license.includes(L) && q.point.startsWith("(8)捕獲規制区域等"));
```

## 4. 法改正対応

| 項目 | 内容 |
|---|---|
| **拘禁刑** | 2025年6月1日施行の改正刑法により懲役・禁錮が一本化。`law06` `law46` を修正済み。「懲役」の残存 **0件** |
| **緊急銃猟** | 2025年9月1日施行・法第34条の2。**6問を新規追加**（`law098`〜`law100`, `law108`〜`law110`） |

緊急銃猟の要件（狩猟読本の記載に準拠）:

1. 危険鳥獣（**ヒグマ・ツキノワグマ・イノシシ**）が人の日常生活圏（住居、広場、乗り物等）に侵入し、又は侵入するおそれが大きいこと
2. 危害を防止する措置が緊急に必要であること
3. 銃猟以外の方法では的確かつ迅速な捕獲等が困難であること
4. 避難等によって地域住民等に弾丸が到達するおそれがないこと

→ 市町村長が、危険鳥獣の銃猟を**捕獲者に委託して実施させることができる**（法第38条の適用除外）

## 7. 第2版で修正した誤り

読本・例題集の原典と照合した結果、前版の推測ベースの記述に次の誤りが見つかった。いずれも正しい記述に差し替え済み。

| 論点 | 前版の誤り | 原典の記述 |
|---|---|---|
| むそう網の分類 | 「片むそう・双むそう」の2種類として扱っていた | **穂打ち・片むそう・双むそう・袖むそうの4種類** |
| はり網の分類 | 谷切網のみ言及 | **うさぎ網・谷切網・袋網の3種類**（かすみ網もはり網の一種） |
| かすみ網 | 「はり網とは別物」と読める設問 | **かすみ網ははり網の一種**。棚糸・棚があるのが特徴 |
| はこわな／囲いわな | 「天井の有無・移動可否」で区別 | **半分を超える屋根型の天井部分の有無**で区別 |
| 筒式イタチ捕獲器 | 「筒状の構造で中に入った獲物を捕獲」 | **くくりわなの一種**。糸や針金で首を締める |
| 締付け防止金具 | 目的を曖昧に記述 | **錯誤捕獲個体の解放と損傷軽減**（立木保護は「よりもどし」の効果） |
| 圧縮ガス式空気銃 | プリチャージ式と混同 | **交換式ボンベの液化ガスの気化圧力**を利用。プリチャージ式は別 |

あわせて、原典から次の論点を新規に取り込んだ。

- 網の別称（谷切網＝峰越網／袋網＝地獄網／なげ網＝坂網・坂取網）
- つき網となげ網の違い（なげ網はメタハサミがはずれて袋状になる／つき網は閉じずたるみで捕らえる）
- はり網の張りっぱなし禁止と、**ノウサギ・ユキウサギ用に限る例外**
- スズメは風下から飛来し着陸寸前に脚を伸ばす → その一瞬に網を被せる
- 空気銃の数値（弾丸径4.5/5.0/5.5mm、スプリング式の最大有効射程約30m・最大到達距離約310m）
- 法定猟具から削除された猟具（おし・もちなわ・つりばり・とらばさみ・はご・放鷹）

### 残っている未撮影の範囲

第4章（鳥獣）・第5章（保護管理）の例題ページは一部のみ。追加できれば以下を厚くできる。

- 鳥獣：くちばしの形、尾の長さ、足ゆびの形、角、シルエット、歩行跡、配偶様式、季節移動
- 保護管理：指定管理鳥獣捕獲等事業、認定鳥獣捕獲等事業者、個体数調整の詳細

### 図示問題について

例題集の網猟・わな猟・銃器の例題には「次図の猟具は何か」という**図示問題が多数**含まれている（撮影分では網猟11問中11問、わな猟の冒頭6問など）。本試験でも同じ形式が出る可能性が高い。

現状のアプリはテキストのみのため、これらは構造の言語的説明に置き換えてある。将来的に猟具のイラストを用意できれば、`GUN_PARTS` と同じ要領で図示問題に対応させる余地がある。
