    遊び方・ルール解説

    基本

    操作は START と STOP だけ。計測中は画面のどこをタップしても STOP できます。何を狙うかは モード、どこまで危険を取るかは RISK、毎回のお題は 指令 が決めます。GOOD 以上で「成功」です。

    MODE

    ジャスト：目標タイムぴったりで止める。誤差 0 なら JUST!!。

    ゾロ目：止めた数字の並びで勝負。7.77 は JACKPOT、ほかにゾロ目・連番・π/e/√2・回文・x.00。1 カウント差なら「惜しい!」。1 秒未満で止めた場合は対象外。

    チキンレース：範囲のどこかで爆発する装置。直前で止めるほど高得点。鼓動・警告音・途絶は爆発時刻と無関係です。

    反射神経：琥珀色に光った瞬間に STOP。光る前と、光ってから 100 ms 未満（人の反応として成立しない速さ）はフライング。

    定例実験：日付ごとに固定されたモード・ギミック・指令で挑む 1 日 1 課題。全員同じ条件なので、結果をシェアして比べられます（日本時間 0 時更新）。

    RISK と CHAIN

    RISK は次の計測に乗るギミックの数。SEALED ×1.00 ／ LOW ×1.25 ／ MID ×1.50 ／ HIGH ×1.75。CHAOS ×3.00 は 5 個以上が同時に発動し、失敗すると 0 点。ギミックは START 前にチップで公開されます。

    成功を続けると CHAIN 倍率が上がります（2 連 ×1.2 → 3 連 ×1.5 → 4 連 ×2.0 → 5 連以上 ×3.0）。失敗すると途切れます。CHAIN は挑戦者ごとに記録されます。

    指令

    毎回ひとつ提示されるお題。達成するとボーナス点（倍率の外で加算）。

    対戦

    設定で参加者を入れると交代制に。3ROUND MATCH をオンにすると全員が JUST → ゾロ目 → チキンを 1 回ずつ行い、合計点で勝者を決めます（対戦中は CHAIN なし・各ラウンドの条件は全員共通）。

    表示を乱すギミックが付いていても、判定は常に本当の経過時間です。キーボード：SPACE / ENTER スタート・ストップ、S 設定、ESC 中断。計測中の中断は失敗（0 pt・CHAIN 途切れ）として記録されます。記録はこの端末の中だけに保存され、外部には送信されません。
