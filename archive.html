世界境界線の観測記録

初期フェーズにおける空間ノイズの増幅と、それに伴うレイヤー構造崩壊について。実体化の危機と対策の記録。

Classification: Level 4 / CLASSIFIED
Author: 観測班主任 / 記録局
Date Created: 2026.04.12 09:47:23
Last Modified: 2026.04.15 14:32:15
Version: 2.3 (Patched)
Related Documents: ANM-044, PRO-012

Summary

【追加暗号ログ】空間ノイズの測定値が規定限界の200%を超過。境界線の向こう側から「記述されていない叙述」の逆流を確認。実体化を防ぐため、至急A.C.A.S.へ制圧要請を行う必要がある。

Observations

初期段階の観測では、境界線付近のデジタルノイズが時系列で増加している傾向が見られます。これは通常のシステムエラーではなく、外部からの「干渉」の兆候と考えられます。

特に注目すべき点は、この干渉が「意思」を持つように見えることです。システムログの分析から、特定のパターンで繰り返し記録を改竄しようとする試みが検出されています。

Critical Findings

  • 境界線の周辺で時空間の異常な歪曲を測定
  • 複数のレイヤー間における整合性の喪失
  • 未知の存在による自動的なシステム編集の可能性
  • この記録が最終的にどのような状態で保存されるか不確定

Recommendation

この記録が閲覧されている頃には、おそらく対象領域の再構築（パッチ適用）は完了しているはずだ。だが、その「完了」が本当に完了なのか、それとも「完了したように見せかけられた状態」なのか、それを確認する方法は、もう誰にも残されていないかもしれない。

TOL-001 2026.08.11

ArcaOffice Tabula ── 帳票生成端末

見積書・請求書・納品書・領収書を作成する単一ファイルのツール。入力データは端末内で完結し、外部へ送信されない。

Classification: Level 1 / PUBLIC
Series: ArcaOffice
Version: 1.0（2026年8月）
Format: 単一HTMLファイル
External Access: NONE（外部通信なし）
Status: ACTIVE

何ができるか

見積書・請求書・納品書・領収書の4種類を作成し、印刷またはPDFで出力できます。ブラウザだけで動き、インストールは不要です。

  • インボイス制度に対応 — 適格請求書発行事業者の登録番号、税率別の対象額と消費税額を印字します
  • 軽減税率・非課税 — 明細の行ごとに 10% / 8% / 非課税 を選べます
  • 源泉徴収 — 10.21%（100万円超の部分は20.42%）を自動計算します
  • 収入印紙の判定 — 領収書では、金額から必要な印紙税額を自動で表示します。クレジットカード決済の場合は不要と判定します
  • 書類の変換 — 見積書から請求書へ、請求書から領収書へ、内容を引き継いだまま切り替えられます。変換前の書類は自動で履歴に残ります
  • 取引先・品目のマスタ — よく使う相手先と品目を登録しておけます
  • 書き出し — Excel(.xlsx) と CSV に出せます

用紙は A4 / A5 / A5×2面付け（控え付き）から選べます。明細が増えても自動で縮小して1ページに収めます。

データの扱い

入力した内容は、いま開いているブラウザの中にのみ保存されます。外部に送信されることは一切ありません。

これは「送信しません」という約束ではなく、確かめられる事実です。ファイルの先頭に外部通信を禁止する宣言（Content-Security-Policy の connect-src 'none'）を書いてあるため、仮に送信しようとしてもブラウザ自身が止めます。開発者ツールの「ネットワーク」タブを開いたまま操作しても、通信は1件も発生しません。

作り手を信用しなくても、仕組みとして送信できません。

オフラインで使う

外部ライブラリにもCDNにも依存しない、1つのHTMLファイルです。ダウンロードして手元に置けば、インターネットに繋がっていなくても全機能が動きます。

ただし、画面版と手元版でデータは共有されません（保存先がブラウザ側のため）。移す場合はツール内の「書き出し」→「全データを書き出し（JSON）」をお使いください。

TOL-002 2026.08.11

狩猟記録 Venatio ── 野帳端末

わなの見回りと実包の受払を記録し、印刷できる単一ファイルのツール。電波の届かない場所でも動作する。

Classification: Level 1 / PUBLIC
Series: ArcaOffice
Version: 1.0（2026年8月）
Format: 単一HTMLファイル
External Access: NONE（外部通信なし）
Status: ACTIVE
Related: SECTOR-01 狩猟適性訓練区画

何ができるか

わなの見回り記録と、実包の受払記録を、スマートフォン1台で残せます。

わな見回り

  • わなを登録し、見回りのたびに結果（異常なし／作動・空はじき／捕獲／錯誤捕獲／破損／餌切れ／撤去）を記録します
  • 最後の見回りからの日数をわなごとに表示し、しきい値を超えたものをまとめて警告します
  • 捕獲した場合は、獣種・頭数・性別・推定体重を残せます
  • 設置場所は端末のGPSから取得できます。電波の無い場所のために手入力欄も残してあります

実包管理帳簿

  • 適合実包ごとに受・払・残を記録し、残数を自動で計算します
  • 令和7年3月1日施行の改正に対応しています。ライフル実包以外は、番径に加えて「散弾」「単弾」の別を分けて登録できます
  • 自宅保管の限度（散弾・ライフル実包の合計800個）を超えると警告します
  • 残数がマイナスになった行を検出し、発生箇所を示します
  • 印刷すると、警察の記載例と同じ体裁で出力できます

どちらも CSV に書き出せます。

大切な注意

本ツールは記録の作成を支援するものであり、法定の帳簿様式そのものではありません。

実包管理帳簿の様式は都道府県警察により異なる場合があります。また、電子的な記録のみで法定の帳簿義務を満たせるかは所轄の判断によります。実際の運用は必ず所轄の警察署（生活安全課）にご確認ください。

見回りの頻度や標識の要件、使用が制限されるわなの種類についても、地域ごとに上乗せの規制があります。狩猟者登録時に配布される資料と、お住まいの都道府県の最新情報をご確認ください。

データの扱い

記録はいま開いているブラウザの中にのみ保存されます。わなの設置場所の座標も、捕獲の記録も、外部に送信されることは一切ありません。ファイルの先頭に外部通信を禁止する宣言（connect-src 'none'）を書いてあるため、仕組みとして送信できません。

オフラインで使う

外部ライブラリにもCDNにも依存しない、1つのHTMLファイルです。ダウンロードして端末に置けば、電波の届かない山の中でも全機能が動きます。

抽選ゲーム ── 確率事象制御端末

忘年会・二次会・結婚式の景品抽選をブラウザで行うツール。スロット・レース・イルミネーション・ロケットの4演出から選べる。

Classification: Level 1 / PUBLIC
Series: SECTOR-03 確率事象制御区画
Format: 単一HTMLファイル
External Access: 広告配信のみ（入力データの送信なし）
Status: ACTIVE

何ができるか

宴会・忘年会・新年会・二次会・結婚式などの景品抽選を、その場のプロジェクタやモニタに映して進行できます。ルーレットやビンゴの代わりに使えます。

  • 4種類の演出 — スロット／競馬風レース／イルミネーション点灯／ロケット発射から選べます
  • 景品の登録 — 賞品名と当選数を登録するだけで始められます
  • 参加者名での抽選 — 名簿を入れれば、番号ではなく名前で当選者を出せます
  • ハズレ枠・確率の設定 — 盛り上がりに合わせて当たりの出方を調整できます
  • 当選者の自動除外 — 一度当たった人を次回以降の対象から自動で外します（連続で当たってよい設定にもできます）
  • スマートフォン・タブレット・PCのいずれでも動きます

データの扱い

登録した参加者名も抽選結果も、いま開いているブラウザの中（localStorage）にのみ保存されます。当研究所を含め、外部へ送信されることはありません。

ただし本ツールは、TOL-001・TOL-002 と異なり広告配信スクリプトを読み込みます。そのため外部通信を禁止する宣言（CSP）は入っておらず、完全なオフライン動作は保証されません。会場のネットワークが不安定な場合は、事前にページを開いておいてください。
